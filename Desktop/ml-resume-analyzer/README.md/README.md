# 🧠 Machine Learning Resume Analyzer

This project uses **FastAPI** and **Natural Language Processing (NLP)** to analyze resumes against job descriptions.  
It identifies missing keywords, scores alignment, and gives personalized feedback — perfect for helping candidates tailor their resumes.

---

## 🚀 Features

✅ Extracts key skills and technologies from resumes  
✅ Compares them to job descriptions  
✅ Generates a match score  
✅ Suggests improvements and missing keywords  
✅ Easy-to-use API built with **FastAPI**

---

## 🧩 Tech Stack

- Python 3.11+
- FastAPI
- Scikit-learn
- Pandas
- NumPy
- NLP (basic keyword matching)
- Uvicorn (for local server)
